This corpus freezes Python 4.8.0 Fleet online-signer custody and `sign_federation_document` issuance. Encrypted test bundles are included so native loaders can be proven without embedding raw private keys or calling Python at runtime. Passphrases are test-only constants.

This is not production key material, provider execution evidence, or a cutover of storage/transfer authority.
