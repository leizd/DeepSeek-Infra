This additive corpus freezes the real `evidence-proof-v2` envelope shape and
the `dr-readiness-proof-v1` semantic validator inherited from Python 4.8.0.
It proves that Rust does not accept a bare `status=PASS`, a failed check, or a
self-asserted check whose semantic validator has not yet been migrated.

The v1 through v3 corpus files remain unchanged.
