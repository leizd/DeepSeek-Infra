## 1. Executive Summary

DeepSeek Infra **4.6.2** makes Formal Receipt/Commit mutation and destructive
Ciphertext GC **serializable per Target**. It closes the remaining TOCTOU
windows after 4.6.1's trusted index coverage: fail-closed metadata authority,
exclusive metadata fences, atomic rebuild invalidation, and durable two-phase
GC intents.

Wire protocols remain frozen: `object-set-v1`, Receipt v4, Commit v4,
FastCDC v3, Projection semantics, and randomized Age encryption.

---

## 2. Control schema v6

- `target_metadata_gates` — exclusive per-target lease for `formal-mutation` vs `destructive-gc`
- `ciphertext_gc_intents` — durable Candidate/Validated/Deleting/Reclaimed/Cancelled intents
- Formal mutation always dirties index coverage and advances receipt mutation generation in the same durability boundary as fence acquire

---

## 3. Correctness gates

| Gate | Behavior |
|------|----------|
| A Formal Metadata Mutation Authority | No Receipt write without successful fence + mutation bump; control failure → block |
| B Target Metadata Mutation Gate | Publish and destructive GC mutually exclusive |
| C Index rebuild | `begin_index_rebuild_clear` invalidates then clears atomically |
| D Two-phase GC | Intent binds generation+etag; per-object destructive fence revalidates then CAS delete |
| D′ Fence effect | `renew_target_metadata_gate` / `assert_metadata_gate_current` before DELETE; stale token after lease takeover aborts (leave garbage, never wrong delete) |
| G Coverage | Combined branch floor **95.0%** restored |

---

## 4. What is not in this release

- No wire format changes
- No Raft / multi-node control authority
- No convergent encryption / cross-backup plaintext dedupe
- No new placement/tier optimizers
