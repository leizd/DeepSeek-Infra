## 1. Executive Summary

DeepSeek Infra **4.5.9** upgrades the 4.5.8 Storage Control Plane from
“scan full history and coordinate multiple local job DBs” to a scale-ready
control plane driven by a durable **Lifecycle Transaction Journal** and a
rebuildable **Ciphertext Reference Index**.

Wire protocols remain frozen: `object-set-v1`, Receipt v4, Commit v4,
FastCDC v3, Projection semantics, and randomized Age encryption.

---

## 2. Hard Gates

### Gate A — Lifecycle Transaction Journal

- Drain (and tier) topology mutations journal a lifecycle intent in
  `control.sqlite3` under `BEGIN IMMEDIATE` before/with the topology change.
- DrainJob SQLite rows are projections; crash between topology commit and job
  insert is healed by `reconcile_drain_projections()`.

### Gate B — Ciphertext Reference Index

- `target_objects` + `recovery_object_refs` track live/retired payload refs.
- Retirement GC prefers the index; empty index falls back to fail-closed
  receipt scan.
- Shared ciphertext cannot be GC'd while any live recovery point still refs it.
- Index is rebuildable from formal Target Receipt + retirement marker truth.

### Gate C — Physical Storage Accounting

- Quota/admission prefer `physicalStoredBytes` from the object index.
- Retired-but-pending-GC bytes remain accounted until actual delete.
- Logical recovery-point byte sums are not used as hard capacity truth.

### Gate D — Elapsed-Time Capacity Forecast

- Growth observations are timestamped physical series.
- Horizons report P50/P90 bytes/day and confidence.
- Insufficient evidence → `forecastStatus=unavailable` (no fake huge day count).

### Gate E — Honest Economics

- Cost rates require operator configuration and expose provenance.
- Missing rates → `costStatus=unavailable` (never silent AWS-like defaults).
- Placement still ranks recoverability / domain / RTO / capacity before cost.

### Gate F/G — SLO-Aware Tiering

- Targets declare `storageTier` (`hot`/`warm`/`archive`) and latency class.
- Placement unit is a **Recovery Chain Closure**, not a lone incremental leaf.
- Hot recovery points cannot depend on archive-only ancestors.
- Tier migration copies original ciphertext only (no Age re-encrypt);
  `backupId` and `objectSetDigest` stay stable.

### Gate H — Maintenance Worker Sharding

- Short global planner lease discovers work.
- Execution uses `(workerKind, scopeId)` fencing leases.
- A held archive drain lease cannot block primary repair progress.

### Gate I — Control DB Resilience

- `PRAGMA user_version` + `schema_migrations` ledger.
- `PRAGMA quick_check` fails closed on corruption.
- Online SQLite backup checkpoints supported.

## 4. Upgrade Notes

- Existing 4.5.8 control DBs migrate automatically to schema version 2 on open.
- Operators should supply `storageCostPerGiBMonth` / `egressCostPerGiB` on
  Targets if cost-aware placement budgets are configured; unknown rates no
  longer receive implicit defaults.
- Optional: rebuild object indexes per Target after upgrade for faster
  retirement GC (`backup_object_index.rebuild_index_from_target`).
