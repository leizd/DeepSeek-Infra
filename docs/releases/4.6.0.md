## 1. Executive Summary

DeepSeek Infra **4.6.0** upgrades the 4.5.9 Storage Control Plane into an
**Autonomous Recovery SLO Controller** that stays correctness-safe at
500+ recovery points and 20k+ object references.

Wire protocols remain frozen: `object-set-v1`, Receipt v4, Commit v4,
FastCDC v3, Projection semantics, and randomized Age encryption.

---

## 2. Hard Gates

### Gate A — Scale-Safe Correctness

- Canonical physical ciphertext identity (aliases never inflate usage).
- GC uses SQL-native live-ref checks (no 20k-set materialization fail-open).
- DR Readiness capacity path is zero remote I/O (`probe=False`).
- Recovery chain exact parent walk; missing parent fails closed.
- Tier planner requires exact `storageTier` plus hot/warm ancestor eligibility.

### Gate B — Index Coverage + Pure Capacity Projections

- `target_index_coverage` blocks index-accelerated GC until complete.
- Capacity forecast projections persist on probe; readiness reads projections only.

### Gate C — Recovery Lineage Graph

- Rebuildable `recovery_lineage` graph preferred by chain builder.

### Gate D — RecoveryChainMigrationJob

- Durable chain migration with per-member authenticated sources.
- Intent never marks `executed` on failed member transfer.
- Converges to `converged` / `failed-terminal` under maintenance.

### Gate E — Autonomous Recovery SLO Controller

- Policy `recoveryPlacement` windows map age → Hot/Warm/Archive desire.
- Explainable decisions with ordered reason codes:
  recoverability → lineage → copy/FD/region → RTO → capacity → cost last.
- Cost never overrides topology or recoverability.
- Drift enqueues `plan_chain_migration` when enabled.

### Gate F — Truly Sharded Maintenance

- Repair / rebalance / retirement / chain-migration leases scoped by target.
- A held dest-target repair lease cannot stall free targets.
- Planner still uses a short global lease for discovery only.

### Gate G — Planner-Mandatory MinIO Evidence

- Exact-merge producer extends three-MinIO runner with placement scenario.
- Claims incomplete-lineage reject, coverage GC gate, placement order,
  target-sharded repair, capacity zero-I/O, and wire freeze.

## 3. Compatibility

Unchanged wire surface: object-set-v1, Receipt v4, Commit v4, FastCDC v3,
Projection, randomized Age. Single-host durable control authority only
(no Raft/multi-node consensus in this release).
