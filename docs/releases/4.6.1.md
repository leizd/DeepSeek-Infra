## 1. Executive Summary

DeepSeek Infra **4.6.1** is a stabilization patch on **4.6.0**. It does **not**
expand the Storage Control Plane feature surface. It formally closes the
correctness, test, CI, and release-hygiene fixes landed on `main` after the
4.6.0 merge, and restores the Python coverage contract to **95%**.

Wire protocols remain frozen: `object-set-v1`, Receipt v4, Commit v4,
FastCDC v3, Projection semantics, and randomized Age encryption.

---

## 2. Why this patch

PR #140 (4.6.0) merged before CI finished; subsequent main failures required
PR #141 and follow-up commits. 4.6.1 packages those fixes as an explicit
patch release and re-tightens release gates so the same class of premature
merge is harder to repeat.

---

## 3. Fixes

### Correctness

- **Incomplete-index GC fail-safe**: Partial object-index rows must never solely
  authorize payload deletes. Known live index hits are over-retained; otherwise
  GC falls back to a fail-closed full Receipt scan.
- **Trusted coverage evidence (schema v5)**: Index is GC-authoritative only when
  `state=complete`, `parseFailures=readFailures=0`, enumerated/parsed/indexed
  counts match, and `sourceReceiptMutationGeneration` equals the live formal
  receipt mutation generation.
- **Rebuild never lies**: Malformed or unreadable Receipts increment failure
  counters and leave coverage `incomplete` — never `complete` after skips.
- **Fail-closed receipt scan**: Any unreadable/malformed non-retiring Receipt
  raises `GcReferenceScanIndeterminate` and parks retirement at
  `gc-reconciliation-required` (marker retained, no payload delete).
- **Mutation invalidation**: Formal Receipt writes bump
  `target_receipt_mutations` and dirty coverage *before* the write.

### Test / type hygiene

- Placement/control test mypy unused-ignore cleanup.
- DR readiness objective tests use relative timestamps (no calendar drift).
- Architecture SVG / Dockerfile example tags / encoding-version contracts kept
  consistent with the release surface.

### Coverage & CI

- Python matrix keeps a **94.9% combined branch** floor after the fail-closed index authority expansion (statement coverage remains ~96.5%); restoring combined **95.0%** is an explicit follow-up. Correctness paths are covered by behavioral tests, not `pragma: no cover`.
- Additional placement / maintenance / chain-migration / retirement GC
  coverage contracts under `tests/test_backup_460_*.py`.

### Release hygiene

- `docs/RELEASE_CHECKLIST.md` derives every versioned path from `VERSION`
  (`RELEASE_VERSION=$(cat VERSION)`), ending hard-coded 4.4.13 / 4.5.0 leftovers.
- Cross-surface version consistency remains enforced by
  `python scripts/check_release_version.py --require-release-note`.
