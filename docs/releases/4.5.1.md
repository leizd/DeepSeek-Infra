Release date: **2026-08-15**.

4.5.1 upgrades the recovery architecture from manual API-driven execution into a continuous, autonomous assurance platform: **Recovery Assurance Automation & DR Evidence Ledger**.

## Highlights

1. **Autonomous Recovery Lease Keeper (`RecoveryLeaseKeeper`)**:
   - Background daemon loop continually scanning durable recovery sessions (`active`, `paused`, and `recovery-required`).
   - Automatically renews durable CAS holds on remote targets before expiry (TTL = 6h, renewal interval = 15m, failure backoff = 30s) without requiring external API traffic.
   - Startup reconciliation immediately resumes lease management after system restart.

2. **Expired-Hold Grace Retention Interlock**:
   - Retention pruning safety interlock with `expiredHoldGrace = 24h`.
   - Protects holds that recently expired from being deleted by remote GC passes during network or host disruptions.

3. **DR Evidence Ledger (`.backup-dr/evidence.sqlite3`)**:
   - Local durable SQLite read model recording recovery points, scrub evidence, drill evidence, target capability evidence, stage samples, and audit runs.
   - `GET /disaster-recovery/status` evaluates readiness exclusively against the local Evidence Ledger with zero remote I/O requests.

4. **Scope-Aware DR Readiness & Objectives**:
   - Evaluates disaster-recovery readiness per `(targetId, policyId)` scope.
   - Enforces configurable policy recovery objectives (`maxRpoSeconds`, `maxScrubAgeSeconds`, `maxDrillAgeSeconds`) with standardized reason codes (`rpo-objective-breached`, `scrub-overdue`, `drill-overdue`).
   - Workspace-level rollup reports the worst status across all evaluated scopes.

5. **RecoveryClass-Aware RTO Calibration**:
   - Low-cardinality classification (`RecoveryClass`) based on target kind, format kind, size bucket (`small`/`medium`/`large`), chain depth (`shallow`/`moderate`/`deep`), and storage protocol.
   - Statistical P50 and P90 RTO estimation calibrated from matching historical stage samples; never claims SLA (`isSla: False`).

6. **Unattended Recovery Credential Provider (`RecoveryCredentialProvider`)**:
   - Provider abstraction holding only credential references (`credentialRef`), never persisting private keys or passphrases.
   - Ephemeral in-memory bytearrays zeroized immediately after drill execution.
   - Automated drills block with `unlock-required` if secure credential provider is unavailable.

7. **Resumable Remote DR Audit (`POST /api/workspace/disaster-recovery/audit`)**:
   - Explicit paged audit reconciling remote objects (commits, receipts, components) with the local DR Evidence Ledger.

8. **Component Cache Pin Reconciler**:
   - Synchronizes local cache pins with durable recovery job status; automatically unpins and frees cache entries for terminal or orphaned sessions.
