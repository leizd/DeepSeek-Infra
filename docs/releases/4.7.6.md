**适用版本：** v4.7.6

**副标题：** Production Predictive Control & Verifiable Simulation

4.7.6 把 4.7.5 的预测、优化与 Wave 模型接入真实 production control loop，
消除调用者自报 freshness、actual service 与 zero mutation 的边界。

## 本版闭环

- Wave admission 只接受 production fresh-state bundle；Authority、完整
  RiskSnapshot、容量、running effects、预算、维护窗口或 blast simulation 缺失
  均 fail closed。
- Durable Wave runner 直接执行 Action Journal effect，以单调 execution epoch
  围栏 crash takeover，并复用既有 Repair/Rebalance/Drill effect。
- 公平服务从 terminal effect telemetry exactly-once 结算，调用者不能提交
  actual bytes/duration。
- Maintenance loop 用真实 target probe 自动写入 incarnation-isolated capacity
  observations；MinIO/S3 用 provider 分页对象清单计量，Forecast Registry 自动
  生成 30/90 天记录并在稍后 observation 到期回测。
- `/whatif` 仅接受 hypothetical candidate。系统内部构造 baseline、Forecast、
  price catalog、Authority、running effects 与维护状态。
- Write-deny capability 实际阻断 Storage、Authority、Action Journal、Policy 与
  Target mutation；attempt audit 和 pre/post digests 独立证明零副作用。
- 新增 `predictive-planning-proof-v1` typed payload。Evidence Assembly 必须同时
  获得 report、autonomous proof 与 predictive proof exact artifacts。
- 真实 Three-MinIO E2E 执行 Age Backup、Repair、Rebalance、capacity sampling、
  automatic backtest 和 What-If，并再次查询三端 inventory 证明前后不变。
- Federation 仍只读；tamper、stale/future、same-fleet 和 wire incompatibility
  全部 fail closed。signed federation 与跨 Fleet 写入未引入。

## Evidence 状态

本地真实 Three-MinIO predictive scenario 可生成并语义验证开发 proof，但不能
代替正式 release PASS。正式验收仍要求 final merge SHA 的 CI producer 上传三个
exact artifacts，且全局 Evidence Assembly 通过。

## Wire freeze

object-set-v1、Receipt v4、Commit v4、FastCDC v3、randomized Age、
control-authority-v1、AuthorityCheckpoint v1、dr-readiness-proof-v1 与
evidence-proof-v2 envelope 保持不变。

## 明确不做

Cross-fleet writes、remote autonomous repair、remote policy mutation、signed
federation、multi-primary Authority、Raft/consensus、自动删除副本、自动降低耐久性、
自动主目标晋升，以及任何 Receipt/Commit/object-set/control-authority 版本升级。
