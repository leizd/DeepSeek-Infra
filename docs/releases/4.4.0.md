中文标题：**可移植工作区备份与可验证恢复**

4.4.0 在分享用 Export 之外增加独立的 `restorable-backup` 包。备份仅从显式 Contributor
白名单读取永久数据，使用稳定 JSON、逐文件 SHA-256、Contributor 摘要与 Manifest 摘要，
并以 `.dsibackup` 原子发布。包默认不加密，因此应按完整工作区敏感数据保管。

## 主要能力

- 完整工作区或指定项目备份；可选运行历史、浏览器草稿，默认排除可重建索引。
- 4.3.7 会话 Head、快照和未解决 Conflict Ledger 经摘要校验后进入 Frontend Envelope。
- `Inspect` 在 staging 中检查 Schema、用途、路径、重复项、大小、压缩比和全部摘要，不写正式数据。
- `Apply` 获取恢复屏障，先创建 pre-restore safety snapshot，再按 Contributor 提交；失败回滚。
- 合并恢复遇到同 ID 不同内容时使用来源备份和内容摘要确定性重映射，并重写 JSON 引用。
- 旧标签页收到 `restore_epoch_changed` 后停止交互，要求用户重新载入。
- API 与 `scripts/backup_workspace.py`、`scripts/restore_workspace.py` 共用同一核心。

## 安全边界

包拒绝路径穿越、绝对路径、反斜杠路径、符号/硬链接、设备文件、大小写碰撞、重复条目、
ZIP Bomb、未来 Schema、过深 JSON、未声明文件和 SHA 不匹配。`.env`、本地鉴权 Token、
API Key、Tavily Key、浏览器凭据、PID 与锁文件永不进入备份。分享 Export 不能进入 Restore。

## CLI

```text
python scripts/backup_workspace.py --out workspace.dsibackup
python scripts/backup_workspace.py --project proj-abc123 --include-history --out project.dsibackup
python scripts/restore_workspace.py workspace.dsibackup --inspect
python scripts/restore_workspace.py workspace.dsibackup --apply --mode merge
```

冷备仍可在服务完全停止后复制整个数据卷；在线迁移和灾难恢复推荐使用验证备份。
