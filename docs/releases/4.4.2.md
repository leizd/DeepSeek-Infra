中文标题：**加密备份与外部状态可移植性**

4.4.2 在 4.4.1 的崩溃安全恢复事务上增加两个边界：离开设备的备份可由标准 age v1
格式保护；“完整备份”必须准确说明本地、浏览器和外部持久状态是否都被覆盖。

## 标准 age v1 加密

- 密码模式和 X25519 Recipient 模式都加密完整的内部 `.dsibackup`；外层文件名为
  `.dsibackup.age`，Manifest、Contributor、项目名、文件清单和摘要都在密文内。
- Python 仍负责 Contributor、Manifest、大小/路径限制、Fence、Journal 和事务提交。Rust
  `backup-crypto` helper 只负责 `encrypt-passphrase`、`encrypt-age`、`decrypt-*`、Identity
  生成/派生和 Header 检查。
- ZIP writer 直接写入 helper 的输入流，密文写入临时文件并在完成后原子发布；不会先发布或保留
  最终明文 `.dsibackup`。Contributor staging 仍是受限明文临时区，完成后立即删除，且不承诺
  SSD 物理安全擦除。
- 已有明文 v1 包继续可恢复，不要求迁移。

## Secret 与 Recovery Identity

- 密码和私钥只进入五分钟内存 Secret Slot，Finalize/Unlock 消费后立即清零；重启后必须重新输入。
- Secret 通过第二条继承的匿名管道传给 helper，绝不进入命令行、环境变量、Session、Restore
  Journal、Safety Backup 元数据、文件名、日志或 Trace attribute。
- Recovery Identity 只向 UI/CLI 返回一次；后端只持有公开 `age1...` Recipient。创建 Key 加密
  备份前，用户必须重新导入 Identity，helper 派生 Recipient 并确认匹配。
- 错误密码、错误 Identity、截断和篡改统一为“无法解锁”，失败尝试在内存中节流。

## 加密恢复状态机

```text
Upload → locked → 提供 Secret → age 完整认证 → decrypted → ZIP/Manifest Inspect
```

认证完成前不解析 ZIP，也不返回工作区版本、项目名、Contributor 或 Manifest Digest。认证失败时
删除部分明文；认证成功后仍完整执行路径、条目、展开大小、压缩比、SHA-256、Schema 和冲突检查。
Prepare 创建的 Safety Backup 继承来源保护模式。

## 外部持久状态覆盖

- `strict`：已配置的外部永久数据源不可用时创建失败。
- `best-effort`：允许创建，但 UI 与 Manifest 的 `coverage.unavailableDurableSources` 明确列出遗漏，
  `coverage.complete` 为 `false`。
- 凭据、Redis URL/MCP token、重建索引、租约 Owner、TTL、旧 Fencing Token 和遥测配置永不纳入。

Stateless MCP 不复制 Redis AOF。服务在全局 `stateGeneration` 和 `backupFence` 下导出版本化 JSONL：
任务、幂等 SHA-256 索引和有界 stdout/stderr。恢复不覆盖目标任务；ID 冲突确定性重映射，幂等
索引同步重写。来源 `queued`/`running` 状态一律成为 `interrupted`，Lease 清空且不重新入队，
因此恢复后不会自动运行 pytest。

## UI、CLI 与打包

- React 备份 Drawer 增加不加密/密码/Recovery Key、strict/best-effort 覆盖和加密包解锁控件；
  Secret 只在组件局部状态中短暂存在，关闭 Drawer 或完成操作即清空。
- CLI 使用 `getpass.getpass()`；不提供 `--password <secret>`。
- 发布 ZIP 和 PyInstaller 构建都会编译并携带 helper。源码环境缺失 helper 时能力接口明确返回
  `encryptedBackupAvailable=false`，不会静默退化为明文。

本版本不做云备份、自动/增量/分卷备份、密码找回、Recovery Key 服务端托管、Redis AOF 恢复、
多设备同步或任何 Chat/Agent/Automation/MCP 运行任务重放。
