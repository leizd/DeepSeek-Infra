中文标题：**联邦恢复事务与流式加密完整性**

4.4.3 把 4.4.2 纳入备份范围的 Stateless MCP Redis 状态真正拉进同一个恢复事务域：
本地 Workspace、浏览器 Epoch 和外部持久存储要么一起完整恢复，要么一起回到恢复前。
同时消除了大型密文与大型快照在 Node 和 Python 两侧的整体物化路径。

## 联邦恢复事务

- Stateless MCP 现在是带耐久 Journal 的两阶段参与者：流式 Prepare 只写 staged
  命名空间（不碰正式 Task / Idempotency Key），Commit 在 Restore Fence 下分批安装
  `restorePending` 对象并逐批记录已插入键，Complete 才使导入对象可见。
- Abort 只删除本事务实际插入、且键值仍与 Journal 摘要匹配的 Task Key、Idempotency
  Index 和 Restore Epoch 元数据；恢复前已有数据绝不被误删。
- 提交顺序固定为：本地 staging → 外部 Prepare → 浏览器 Epoch → 三方相同
  commit-intent digest → 浏览器切换 → 本地目录交换 → 外部 Commit → backend-committed →
  外部 Complete → 主服务 Complete → 释放全部 Fence。
- 崩溃恢复先查询外部参与者状态（`GET /internal/restores/{restoreId}`），不再根据本地
  `swapped` 标志猜测 Redis 是否完成；外部存储失联时 Contributor 被围栏为
  recovery-required，而不是静默保留半提交。
- Restore Fence 生效期间：createOrGet 返回 423，claim 不认领新任务，complete 暂缓并在
  Fence 释放后重试，heartbeat 允许续租，普通读取继续允许。

## 流式加密完整性

- Age Header 探测改为继承只读文件句柄：Helper 直接读取密文句柄，解析完 Header（上限
  1 MiB / 64 stanzas）即退出，父进程不再向只读 Header 的子进程推送整个文件，大密文
  不再依赖管道容量。
- Stateless MCP 快照逐行流式导出，HTTP 写入遵循 backpressure，客户端断开即释放
  Backup Fence；恢复使用增量 JSONL 解析器（单行 1 MiB、总量与主备份一致、任务数
  100,000、日志沿用上界、JSON 深度 64），单行越界、半行结束、重复 Task、Complete 后
  仍有数据、代际不一致、摘要不符都会即时中止。
- 恢复 JSONL 只上传一次（Prepare 携带 `X-Transaction-Digest` 与 `X-Content-SHA256`），
  之后 Commit/Abort 只传 Restore ID 与事务摘要；Python 侧下载与上传都使用带 SHA-256
  Receipt 的流式传输，不再 `read_bytes()`，外部路径与本地 5 GB 上限对齐。

## 覆盖证明

- 每个备份会话创建时冻结 Contributor Plan（planId、策略、能力摘要、选中/不可用/排除
  状态）；Finalize 重试不再重新探测外部在线状态。
- Manifest Coverage 只能由实际写入的 `BackupContribution` 生成并双向断言：included
  Contributor 必须有 Payload、Manifest 条目与摘要，每个 Payload 必须出现在 Coverage。

## 恢复连续性

- 加密恢复返回 `secretState`（`not-required` / `available` / `expired` /
  `required-for-safety-backup`）；秘密过期或服务重启后可在 UI 重新提供密码/Identity，
  后端用原密文摘要验证后重新挂接，无需重新上传备份包，已确认的 Manifest 不被替换。
- 首次 Inspect 后只保留密文原包与一个经过验证的 extracted tree，完整明文 ZIP 立即
  删除；Prepare 以 Manifest 逐文件 SHA 与树摘要重新核验 extracted tree。
- 明文 v1 与 4.4.2 age 备份继续兼容，不引入自动备份、云目标、增量/分卷或密码找回。

- Python：`pytest tests/test_backup_crypto.py tests/test_workspace_backups.py` 覆盖
  联邦往返、单次上传、Abort 精确删除、崩溃状态恢复、Coverage 冻结与篡改拒绝、秘密
  重挂与驻留边界。
- Node：`npm run check --prefix stateless-mcp` 覆盖 staged 事务、Fence 423/延迟完成、
  增量解析器、流式导出与中断不重放。
- Rust：`cargo test --locked --manifest-path rust/Cargo.toml -p backup-crypto` 覆盖
  有界 Header 探测、截断/超大/Stanza 洪泛拒绝与多 Recipient 识别。
