Status: **in development; not release-ready**.

4.5.0 freezes object-set-v1, Receipt v4, Commit v4, randomized Age encryption,
Projection semantics, and permanent Whole-Age compatibility. Implementation is
tracked by the approved [specification](../specs/4.5.0-production-recovery-orchestration.md),
[ADR-0044](../adr/ADR-0044-production-recovery-orchestration.md), and
[Gate checklist](../../tasks/todo.md).

No Gate A-G item or CI-only Evidence is considered PASS until the corresponding
behavior has run successfully. This draft will be updated with implemented
behavior and verified evidence as each atomic slice lands.

Implementation is complete through Gate F. Recovery Jobs now provide durable
component transfer state, verified encrypted caching, projection-plan reuse,
bounded pipelining, renewable holds, pause/resume/abort, capacity preflight,
bounded redacted telemetry, read-only DR readiness, and an isolated manual
Recovery Drill that cannot enter the live federated commit path. Gate F focused
tests preserve a byte-identical live Workspace under successful and injected-
failure Drills and scrub every known plaintext staging path. Gate G real
MinIO/Age, subprocess fault, frozen-compatibility, full-gate, and CI Evidence is
still required before release readiness can be claimed.
