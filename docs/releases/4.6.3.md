## 1. Executive Summary

DeepSeek Infra **4.6.3** starts **Disaster-Recoverable Control Authority**: when the
local Storage Control Plane DB is lost or corrupt, a fresh process can rebuild
non-rebuildable control truth from secretless, hash-chained
`control-authority-v1` checkpoints — without Raft, multi-primary, or putting
credentials into Target metadata.

This drop is an **implementable skeleton** with unit-tested contracts. Full
three-MinIO disaster E2E, RPO=0 mutation anchoring, and Commit-authenticated
formal truth rebuild remain follow-through on the same release line.

Wire protocols remain frozen: `object-set-v1`, Receipt v4, Commit v4,
FastCDC v3, Projection semantics, and randomized Age encryption.

## 3. control-authority-v1

```text
control/authority/checkpoints/0000000000000042.json
control/authority/head.json
```

Checkpoint carries:

- policies (revision + placement/drain/promotion epochs)
- sanitized targets (locator + `credentialReference` only)
- receipt mutation generations

**Forbidden:** S3 access/secret keys, Age identity/private keys, API keys, OAuth tokens, passwords.

Generations are hash-chained (`previousDigest` → `payloadDigest` → `digest`).
Same generation / different digest → `control-authority-divergent` (fail closed).

## 6. What this release does **not** do

- No Raft / multi-primary / quorum consensus theater
- No Receipt v5 / Commit v5 / convergent encryption
- No secrets inside authority checkpoints
- No in-place repair of a corrupt control.sqlite3 (quarantine + fresh DB)

## 7. Acceptance line (target)

> DeepSeek Infra 4.6.3 must allow recovery after total local control authority

> Target access, secretless `control-authority-v1` history, and Commit-authenticated
> formal truth — with mutations fail-closed until recovery completes.

Delivers authority format, recovery state, reconstruct path, RPO=0 store/FS
anchor (including promote/drain/topology mutations), startup outbox drain,
Commit-authenticated formal truth rebuild, and real three-MinIO disaster E2E.
