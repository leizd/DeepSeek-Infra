## 开发基线

4.7.4 的目标是把 4.7.3 的真实存储副作用升级为持久化、可审计、
Evidence-closed 的自治运维层：真实 Receipt/Commit bytes proof、完整 DAG
多波次调度、持久化风险与公平服务历史、强制传输预算、安全抢占，以及
Fleet SLO/burn rate/readiness。

当前文件只固定实现与兼容性合同，不宣称 Gate A-N 已通过。只有 exact-merge
CI 的真实三 MinIO、独立进程、Evidence Assembly、coverage、eval 和 release
门禁全部成功后，才可将对应条目标记为通过。

## 冻结合同

`object-set-v1`、Receipt v4、Commit v4、FastCDC v3、randomized Age、
Projection semantics、`control-authority-v1`、AuthorityCheckpoint v1 和
`dr-readiness-proof-v1` 保持不变。
