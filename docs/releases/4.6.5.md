## 1. Executive Summary

DeepSeek Infra **4.6.5** completes the Control Authority correctness line started in 4.6.3/4.6.4:

- Production `AuthorityReplicaProvider` bootstrap before Startup Verdict
- Explicit genesis ceremony when replicas are configured but empty
- Logical monotonic head CAS (`generation=N+1` + `previousDigest`) plus physical ETag CAS
- Cross-replica canonical ancestry (not highest-generation-wins)
- Crash-atomic authority mutation journal (control schema **v8**)
- Durable `controlBootEpoch` inside `control-authority-v1` checkpoints
- Activation only after authority restore (+ optional formal-truth gate)
- Fresh-process Evidence (new interpreter, no inherited TargetStore globals)

Wire formats remain frozen.

  (`prepared` → `anchoring` → `durable`, plus `remote-outcome-unknown` / `divergent` / `superseded`)

  - `controlBootEpoch`

## 4. Startup order

```text
parse bootstrap / env replica locators
  → resolve credential references (no secrets in checkpoints)
  → AuthorityReplicaProvider.discover()
  → Startup Authority Verdict
  → workers only if allowWorkers
```

Fresh process with remote authority and missing local DB → **RECOVERY_REQUIRED**, never auto ACTIVE genesis.
