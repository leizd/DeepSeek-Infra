## Overview

Version 5.0.0 will deliver the full native Rust + Go runtime architecture:
- `deepseek-edge` (Rust): Public HTTP/SSE listener, MCP codec, RAG tokenization, and deterministic policy enforcement.
- `deepseekd` (Go): Control plane orchestrating desired state, scheduler leases, ActionJournal, Agent DAG, resilience, and federation.
- `deepseek-worker` (Rust): Data plane executing storage, transfer, crypto, proofs, and tool sandboxing.
- `frontend` (TypeScript): Pure static assets served by the edge.
- Zero production Python execution, zero shared databases, zero CGO/C-FFI mainlines.

Current status: the checked-in native code is migration scaffolding. It is not
production-authoritative and does not satisfy any 4.9.x or 5.0 release exit gate.
The Go client and Rust worker binary now cross the generated gRPC boundary on
IP-literal loopback and prove fail-closed admission while worker authority is
uninitialized. This is not a successful effect path: authenticated authority
synchronization, production transport security, and durable proof-bound effect
execution are still absent.
