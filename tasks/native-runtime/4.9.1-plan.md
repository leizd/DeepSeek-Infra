## Overview

Version 4.9.1 tracks the Rust Storage and Transfer Plane cutover across 13 data and security domains.
The cutover is still in progress: Python remains the production storage authority until every phase below
has provider-backed evidence. The current native slices implement strict `object-set-v1`, Receipt v4,
Commit v4, signed replica-attestation verification, and the exact sovereign federation transfer journal
with SQLite durability and transactional CAS. Rust now also independently recomputes the complete
`predictive-planning-proof-v1` security binding instead of accepting declared PASS values. These slices
do not yet move payload bytes or authorize remote effects.
