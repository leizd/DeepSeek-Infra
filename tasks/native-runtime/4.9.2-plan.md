## Overview

Version 4.9.2 makes Rust the only public listener and owner of all fast/data/security endpoints.
Public routes (`/healthz`, `/metrics`, `/v1/models`, `/v1/chat/completions`, `/mcp`, `/.well-known/agent-card.json`, `/a2a`)
are served natively by `deepseek-gateway`, with `/api/*` reverse-proxied to the Go control plane.

Status: **in progress**. The canonical paths are registered, but only foundation
handlers are present. Unwired chat, model catalog, MCP, A2A, agent discovery, and
unconfigured Go proxy paths fail closed; route registration is not evidence of edge authority.

## 2026-09-06 public proxy isolation repair

- Removed public forwarding of Go `/internal` management routes, including the
  production SPA fallback path. A pre-fix HTTP regression observed four private
  handler calls from a direct request and encoded/normalized aliases.
- Public `/api/*` forwarding preserves the encoded path, query semantics, method
  and body. It rejects path normalization and CONNECT, strips hop-by-hop headers,
  disables redirects, ambient proxies and automatic retries, and streams response
  errors without replacing them with an empty success.
- Fresh adversarial review found the CONNECT tunnel case and valid apostrophe
  queries; both are covered by regression tests. The second review found no further
  concrete issue under this bounded proxy contract.
- Local Rust 1.85 verification: gateway 54 tests passed, zero skipped;
  gateway all-target/all-feature Clippy with `-D warnings` passed. Contract check
  passed with 40 corpora, 29 versions, 43 domains, 7 protos and 10 generated outputs.

The authenticated proxy task above remains open. Private-route isolation does not
implement public authentication, chat/MCP/A2A parity, authenticated inter-service
transport or production authority ownership. These local regressions are not
exact-head CI or provider-backed release evidence.
