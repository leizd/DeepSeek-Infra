## Overview

Version 4.9.2 makes Rust the only public listener and owner of all fast/data/security endpoints.
Public routes (`/healthz`, `/metrics`, `/v1/models`, `/v1/chat/completions`, `/mcp`, `/.well-known/agent-card.json`, `/a2a`)
are served natively by `deepseek-gateway`, with `/api/*` reverse-proxied to the Go control plane.

Status: **in progress**. The canonical paths are registered, but only foundation
handlers are present. Unwired chat, model catalog, MCP, A2A, agent discovery, and
Go proxy paths fail closed; route registration is not evidence of edge authority.
