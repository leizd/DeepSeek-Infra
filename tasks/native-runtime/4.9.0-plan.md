## Overview

Version 4.9.0 implements the Go Control Plane Foundation in shadow mode. Python remains production-authoritative.
Go `deepseekd` evaluates scheduler, risk, wave, federation, and agent admission decisions in an isolated shadow plane,
and CI strictly enforces:
```text
pythonDecisionDigest == goDecisionDigest
```
