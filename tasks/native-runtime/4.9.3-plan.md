## Overview

Version 4.9.3 moves every control domain to Go through fenced, reversible ownership cutovers.
Old Python writers are mechanically denied, and Go controller kill/takeover preserves exactly-once
effect identity and fencing.

Status: **in progress**. The checkpoint compatibility, mechanical-denial primitives,
isolated SQLite shadow store, and authenticated Go-to-Rust epoch-install channel
below are implemented, but
`release/native_runtime_go_control_store_v1.json` still declares `mode: shadow`. No production
control domain is claimed as cut over. SQLite persistence and signed epoch install are
substrates for later authority work; they are not production control-plane ownership.

## Completed in the SQLite shadow-store slice

- JSON shadow file store (`manifest.json` / `writer.json` / atomic replace) removed from the production Go path. Legacy markers are rejected and left in place.
- Isolated database path `go-control/control.sqlite3` with Python path and Python SQLite filename rejection.
- Versioned schema migration in one transaction: bootstrap metadata, strict domain tables, append-only `control_events`, immutability triggers, `PRAGMA user_version`.
- Durable writer lease / fencing in `control_writer`, claimed and renewed inside `BEGIN IMMEDIATE` transactions.
- Record CAS on revision plus legal state transitions; fenced domains validate execution epochs in the same transaction.
- Event journal insert is in the same transaction as the record write; later-statement failure rolls back both.
- Corruption detection: digest mismatch, non-canonical payload, unknown state, orphaned/missing events, regressing event metadata, schema/revision/state inconsistency.
- Failure injection proves record/event/writer/migration/rollback abort does not commit partial domain state.
- Symlink database files are rejected. Identity inspection uses an immutable read-only SQLite URI so a foreign file is not modified by WAL/SHM or a writer lease before it is rejected.
- Unknown SQLite user objects, incomplete Go control markers, extra migrations, and `user_version`/`schema_version` mismatch fail closed.
- SIGKILL-style recovery is allowed only for an empty SQLite header with zero user objects. Arbitrary foreign SQLite files are not auto-adopted.
- Control payloads recursively reject passwords, tokens, credentials, and PEM/Age private-key material, including nested objects, arrays, and punctuation/case variants. `credentialReference`, digests, IDs, providers, and `fencingToken` remain allowed.
- SQLite driver is `modernc.org/sqlite` (CGO-free). `MutateProduction` still returns `MUTATION_DENIED`.
- Catalog `release/native_runtime_go_control_store_v1.json` remains `mode: shadow`.
- Frozen `control-authority-request-v1` (compat v7) with canonical bytes, digest, and fail-closed Python/Go/Rust verification.
- Schema v2 persists per-domain cutover state and an append-only cutover journal. Every domain starts in `shadow` with Python as owner. `policy` is the first dual-evaluate candidate. Transitions to `go_authoritative` (and later) return `CUTOVER_NOT_AUTHORIZED`. Store catalog `mode` remains `shadow`.
- Additive Worker RPC `InstallAuthoritativeEpoch` carries the signed canonical document plus a matching `ActionFence`. Rust verifies the document against local signer/fleet/environment/fencing/replay state before installing a live epoch. Go signs with a dedicated `ctrl-signer-*` key and never treats a local verify as production authority. `MutateProduction` remains `MUTATION_DENIED`. Shadow mode is unchanged.

## Explicitly not done

- Production mutation authorization. The authenticated channel can install a worker live epoch in shadow mode; it does not authorize `MutateProduction` or switch the Go control store out of shadow. Go must not locally pretend a Rust rejection succeeded. The in-process `install_authoritative_epoch` helper remains test-only and is not exposed as an unauthenticated RPC.
- Control-domain-by-control-domain cutover, ownership handoff, or fencing-authority migration.
- Production rollback path and shadow → authority switch proof.
- Go holding Federation / production root private keys, or storing secret material in control SQLite.
- Ubuntu CI race evidence. Local Windows `go test -race` is blocked by an existing MinGW/toolchain defect and is **not** recorded as passing.
- Exact-head release PASS for ruff/mypy/eval/security/provider runners.
