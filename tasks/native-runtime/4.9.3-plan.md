## Overview

Version 4.9.3 moves every control domain to Go through fenced, reversible ownership cutovers.
Old Python writers are mechanically denied, and Go controller kill/takeover preserves exactly-once
effect identity and fencing.

Status: **in progress**. The checkpoint compatibility and mechanical-denial
primitives below are implemented, but `release/native_runtime_go_control_store_v1.json`
still declares `mode: shadow`; no production control domain is claimed as cut over.
The shadow JSON publisher now rejects serialization failures before publication
and uses same-directory temporary files, file synchronization, and platform
replacement (with parent-directory synchronization on non-Windows). This reduces
torn-write exposure, but it is not cross-process CAS or an authoritative database.
